# 新北市立頭前國民中學 115學年度校慶運動大會田徑賽事 - 智慧賽務與即時榜單系統

本系統為專為新北市立頭前國民中學 115 學年度校慶田徑運動大會量身打造之**純前端（HTML5 / CSS3 / JavaScript）智慧賽務管理與即時公佈榜單系統**。無須安裝任何後端伺服器或資料庫環境，零延遲即時運算，支援電腦、iPad、Android 平板（直立/橫向）與大螢幕投影，可直接雙擊 `index.html` 離線執行或一鍵部署於 GitHub Pages。

---

## 🌟 系統亮點與特色

### 1. 跨裝置與大螢幕相容架構
* **純前端架構**：零伺服器依賴，靜態網頁直接載入 115 學年度全校所有賽程、道次與選手完整名單（完全無失誤完整讀取）。
* **大螢幕投影模式 (Projector Mode)**：一鍵切換高對比、超大字體模式，專為體育館與操場大螢幕、電視牆與投影機設計。
* **平板最佳化 (iPad / Android)**：大按鈕觸控設計，支援裁判於田徑場邊即時點選輸入成績與調整犯規次數。

### 2. 雙模式資料同步方案
* **單機/離線模式**：
  * 自動保存於瀏覽器 LocalStorage，斷網斷電資料不遺失。
  * 支援賽事資料 JSON 檔案一鍵匯出備份、匯入還原，以及一鍵還原至 115 官方初始名單。
* **多人即時雲端同步模式 (Google Sheets + Google Apps Script)**：
  * 提供即開即用的 `google_apps_script.js` 部署腳本。
  * 支援設定 Web App URL，每 5 秒自動輪詢（5s Polling）拉取最新成績。
  * 組長於司令台平板鍵入成績後，大螢幕與全校師生手機、平板即時連動變更名次！

### 3. 分權設計（前後台隔離）
* **前台（全校公開）**：
  * **即時大字體名次榜單**：包含前三名金銀銅牌頒獎台視覺（Podium）。
  * **預賽晉級名冊**：前 12 名亮綠標籤「晉級決賽 (Q)」，第 13、14 名標示「候補 1 (R1)、候補 2 (R2)」。支援「跨組總排行」與「分組道次檢視」雙軌切換。
  * **班級出賽與檢錄查詢**：選取班級（如 701）與日期，即時列出全班出賽選手、項目、道次、節次與地點，醒目標示「比賽前 20 分鐘檢錄集合提醒」，並支援**一鍵列印班級通知單**。
* **後台與內部工作看板（管理者登入保護）**：
  * **隱藏式保護**：未登入前，網頁導覽列不顯示「體育組裁判執勤看板」，且網頁介面上不呈現任何帳號密碼提示。
  * **管理者雙帳號支援**：
    1. 帳號：`tqjh888` / 密碼：`tqjh888`
    2. 帳號：`jenny` / 密碼：`123456789`
  * 登入後自動於導覽列解鎖「👔 體育組裁判執勤看板」與「🔒 後台成績登錄與管理」。
  * 體育組內部裁判看板：點選教師姓名（忠哲、騰毅、兆裕、承瑋、惠芳、黃威、嘉慶、淑靜、明昌、聰達、蕭豐、虔怡）即刻展現出勤節次與執勤崗位清單，並支援**一鍵複製專屬 LINE 廣播通知文字**。

## 🧮 核心競賽規則與特殊演算法

### 1. 大隊接力（並列規則）
* **參賽架構**：七、八、九年級各 16 個班（701～716、801～816、901～916），其中 716、816、916 為體育班。
* **計時加罰**：以秒數記錄，犯規一次加罰 5 秒（`最終時間 = 原始秒數 + 犯規次數 × 5`）。
* **並列邏輯**：
  1. 普通班（共 15 個班）彼此獨立排序，產出第 1 名至第 15 名。
  2. 體育班成績比普通班第 1 名快（或相等）：體育班與普通班第 1 名**並列第一名**；普通班第 2 名仍維持第二名，其餘普通班名次順位不受擠壓。
  3. 普通班第 1 名比體育班快：第一名僅由該普通班獨得。
  4. 體育班成績大於普通班第 1 名、小於等於普通班第 2 名：體育班與普通班第 2 名**並列第二名**。
  5. 體育班成績大於普通班第 2 名、小於等於普通班第 3 名：體育班與普通班第 3 名**並列第三名**，以此類推。

### 2. 田賽（鉛球、跳遠）
* 選手三次試擲/試跳，系統自動篩選「有效最大值（最佳成績）」進行降冪排序，輸入完畢即刻重排；決賽直接取前 8 名優勝。
* 平手時自動比對次佳試擲成績；支援公尺小數或 X/F 犯規標記。

### 3. 中長跑徑賽（800M、1500M）
* 支援「分:秒.毫秒」（如 `2:35.40`）或純秒數輸入，自動換算總秒數。
* 跨組起跑，合併所有分組時間依升冪統一排行，決賽直接取前 8 名優勝。

### 4. 短跑預賽與晉級（100M、200M）
* 跨組依秒數升冪排序，取前 12 名晉級決賽 (Q)，第 13、14 名標示候補 1 (R1)、候補 2 (R2)。
* 支援「分組檢視」（按組別道次排列，方便裁判順道次登記）與「跨組總排名檢視」。

## 🚀 快速開始

### 本機直接執行
1. 在 Windows 檔案總管中，直接雙擊 `index.html`，即可在任何瀏覽器（Chrome、Edge、Safari、Firefox）中開啟使用。
2. 無需安裝 Node.js、Python 或 Web Server，隨開即用！

### 部署至 GitHub Pages
1. 將本專案上傳至 GitHub 儲存庫。
2. 在儲存庫的「Settings」 -> 「Pages」中，將 Source 設定為 `main` 分支的 `/ (root)`。
3. 儲存後幾秒內即可獲得專屬網址（例如 `https://your-name.github.io/AthleticEvents/`），供全校師生與大螢幕掃描 QR Code 開啟！

### 設定多人 Google 試算表同步
1. 參考 `google_apps_script.js` 內建指引，在 Google 試算表中建立 Apps Script 並部署為網頁應用程式 (Web App)。
2. 在本系統後台點選【☁️ 多人雲端同步設定】，貼上 Web App 網址並勾選「啟用每 5 秒自動輪詢同步」即可。
